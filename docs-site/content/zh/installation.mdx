# 安装

在 Mac 上安装 KanVibe Desktop 来管理 AI 编程任务，再连接 iOS 或 Android Mobile 应用，从手机或平板继续工作。Desktop 通过 Homebrew Cask 安装；Mobile 目前需要从源码构建。请查看 [Mobile 构建与连接指南](/zh/mobile)。

## 前置条件

| 依赖 | 是否必需 | 用途 | 安装示例 |
| --- | --- | --- | --- |
| Git | 必需 | 创建和清理 branch、worktree | `brew install git` |
| Herdr | 推荐 | 默认会话后端，已在 0.9.5 验证 | 在 KanVibe 中选择 `herdr` 并确认安装提示 |
| tmux | 可选 | 替代会话后端 | `brew install tmux` |
| GitHub CLI `gh` | 必需 | PR URL 查询与 GitHub 工作流 | `brew install gh`，然后 `gh auth login` |
| zellij | 可选 | 替代会话后端 | `brew install zellij` |

若不想使用多路复用器，可选择 `terminal` 会话类型。此时 shell 由 KanVibe 直接持有，应用退出或远程连接断开时，正在运行的工作也会一并消失。如果打算让任务长时间无人值守地运行，建议安装 Herdr、tmux 或 zellij。

创建任务、创建分支或连接终端时选择 `herdr`，KanVibe 会检查本机或选定的 SSH 主机。若未安装，确认提示后会在该主机运行[官方安装程序](https://herdr.dev/tui/docs/install/)，安装到 `~/.local/bin`，不修改 shell 启动文件。取消后任务保持不变。安装失败时会显示错误；请检查网络连接和目录写入权限后重试。

## 使用 Homebrew 安装

```bash
brew install --cask rookedsysc/kanvibe/kanvibe
open -a KanVibe
```

当 KanVibe 进入官方 Homebrew Cask 后，可使用：

```bash
brew install --cask kanvibe
```

## 更新与卸载

```bash
brew update
brew upgrade --cask kanvibe
```

```bash
brew uninstall --cask kanvibe
brew untap rookedsysc/kanvibe
```

## 从手机继续工作

运行 Desktop 后，按照 [Mobile 指南](/zh/mobile)构建应用并输入六位连接码。手机必须能通过本地或私有网络访问电脑地址。后台推送需要另外配置 Firebase/APNs 和 Desktop 中继。
