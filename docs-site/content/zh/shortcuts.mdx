# 快捷键

KanVibe 明确区分全局、看板和任务详情快捷键，让终端焦点保持可预测。

<div className="kv-kbd-grid">
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + F</kbd><strong>看板搜索</strong><p>搜索当前可见项目和任务文本。</p></div>
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + O</kbd><strong>快速任务搜索</strong><p>按分支名或项目名查找任意任务。</p></div>
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + P</kbd><strong>项目过滤</strong><p>切换看板中可见的项目。</p></div>
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + I</kbd><strong>通知中心</strong><p>打开 AI 代理状态和事件通知。</p></div>
</div>

## 完整快捷键表

| 快捷键 | 范围 | 操作 |
| --- | --- | --- |
| `Cmd/Ctrl+F` | 看板 | 搜索当前可见项目/任务文本 |
| `Cmd/Ctrl+Shift+O` | 全局 | 按分支名/项目名打开快速任务搜索 |
| `Cmd/Ctrl+Shift+P` | 看板 | 打开项目过滤下拉框 |
| `Cmd/Ctrl+Shift+I` | 看板 | 打开通知下拉框 |
| `Cmd+[` / `Cmd+]` (macOS), `Ctrl+[` / `Ctrl+]` (Linux) | 全局 | 在应用历史中后退/前进 |
| `Cmd/Ctrl+Shift+N` | 全局 | 在新窗口中打开当前页面 |
| `Cmd+Option+1/2/3` (macOS), `Alt+1/2/3` (Linux) | 任务详情 | 激活信息、状态/hooks、AI 聊天 dock 项 |
| `Cmd+Option+4` (macOS), `Alt+4` (Linux) | 任务详情 | 存在 PR 时在浏览器中打开 PR |
| `Cmd/Ctrl+N` | 全局 | 打开新建任务弹窗。在快速任务搜索中则基于高亮任务创建 branch TODO |
| `↑ / ↓ / Enter / Shift+Enter / Esc` | 快速任务搜索 | 移动选择、打开、新窗口打开、关闭 |
| `↑ / ↓ / Enter / Esc` | 项目过滤 | 移动选择、切换、关闭 |
| `↑ / ↓ / Space / Enter / Esc` | 通知 | 移动选择、标记已读、打开目标、关闭 |

## 终端标签页

标签页操作在任务详情的终端可见时生效，关闭窗口则在任何界面都可用。对 tmux 和 zellij 会话，这些快捷键会直接操作多路复用器自身的 window / tab。

| 快捷键 | 操作 |
| --- | --- |
| `Cmd/Ctrl+T` | 新建标签页 |
| `Cmd/Ctrl+W` | 关闭当前标签页；若是最后一个标签页则一并关闭窗口，在没有终端的界面上则直接关闭窗口 |
| `Cmd/Ctrl+Shift+W` | 无论有多少标签页都直接关闭窗口 |
| `Cmd/Ctrl+Shift+[` / `Cmd/Ctrl+Shift+]` | 上一个 / 下一个标签页 |
| `Cmd/Ctrl+1` ~ `Cmd/Ctrl+5` | 直接跳转到第 1~5 个标签页 |

<div className="kv-note">
  在 Linux 上这些快捷键使用 `Ctrl` 组合，因此终端内的 `Ctrl+T`（交换字符）、`Ctrl+W`（删除单词）、`Ctrl+[`（ESC）不会再传递给 shell。
</div>

## Vim 模式

在看板上使用 h/j/k/l 移动焦点、`n` 新建任务、`dd` 删除、`:move` 更改状态、`/` 搜索，全部 Vim 风格操作。默认为**开启**状态，可在设置 → 键盘 → "Vim 风格看板操作"中切换。

<div className="kv-note">
  关闭 Vim 模式后，方向键焦点导航仍然可用。
</div>

### Vim 快捷键表

| 快捷键 | 操作 |
| --- | --- |
| `h` | 将焦点移到左侧列 |
| `j` | 在同一列中向下移动焦点 |
| `k` | 在同一列中向上移动焦点 |
| `l` | 将焦点移到右侧列 |
| `n` | 打开新建任务弹窗 |
| `dd` | 删除聚焦的任务（显示确认对话框） |
| `/` | 打开看板页面搜索 |
| `:` | 打开命令输入框 |

### `:move` 命令

在命令输入框（`:`）中输入 `move` 加状态名，即可更改聚焦任务的状态。按 `Tab` 可补全唯一的命令/状态前缀，例如 `move re` → `move review`。

```
:move progress
:move pending
:move review
:move done
:move todo
```

也支持缩写：`t`（todo）、`prog`（progress）、`pend`（pending）、`rev`（review）、`d`（done）。
