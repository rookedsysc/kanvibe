## 看清每个任务的进展

无需逐个寻找终端标签。看板将项目、分支、PR 和会话信息放在一起，支持的代理 hooks 会随工作进展自动更新任务状态。

## 在保留任务上下文的终端里继续

基于分支的任务将 git worktree（分支的独立工作目录）与终端会话连接起来。运行代理、查看差异与对话记录，或亲自输入命令。搜索、项目筛选和面板快捷键让下一步操作触手可及。

## 离开电脑，也能继续同一个任务

KanVibe Mobile 连接到运行中的 Desktop 应用。查看看板、打开任务的真实终端并输入命令、添加 shell 标签，或切换已保存的电脑。手机按状态显示任务列表，平板显示看板。

Mobile 是需要从源码构建的早期预览版，目前界面为韩文。Desktop 必须保持运行且能通过网络访问，任务须使用 tmux、zellij 或 terminal 会话；Mobile 暂不支持 Desktop 默认的 Herdr。后台推送需要额外配置。请查看 [Mobile 安装与连接指南](/zh/mobile)。

## 在电脑上开始，在需要的地方继续

1. **注册仓库。** 扫描本地或远程项目，将 worktree 分支加入看板。
2. **启动任务。** 在分支工作区运行代理，通过看板跟踪状态。
3. **连接手机。** 输入一次 Desktop 连接码，即可在 Mobile 打开同一批任务和终端。需要在手机上使用的任务，请选择 tmux、zellij 或 terminal 会话。
