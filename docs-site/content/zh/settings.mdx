# 设置

KanVibe 设置页把项目注册、显示偏好、通知、任务创建默认值和后台 Sync 集中在一个地方管理。

## 点击通知直接进入任务

- 通知中心和浏览器通知会提示 AI 代理状态变化、PR 事件和后台 Sync 事件。
- 点击已关联任务的通知，会直接打开该任务的详情工作区。
- 限制通知状态后，可以只保留 PENDING 提问或 REVIEW 待检查等真正需要关注的事件。

## 项目注册与清理

- 扫描本地或 SSH 主机上的目录，把 git 仓库注册为 KanVibe 项目。
- 在项目列表中查看每个项目的 repo path、默认分支和 SSH host。
- 不再需要 KanVibe 跟踪的项目，可在设置页删除。
