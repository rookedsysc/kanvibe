# 设置

KanVibe 设置页把显示偏好、终端 pane 配置、通知、任务创建默认值和后台 Sync 集中在一个地方管理。设置会保存到应用数据库中，其中多项会在保存后立即反映到看板或任务详情工作区。

## 外观

| 设置项 | 选项 | 行为 |
| --- | --- | --- |
| 主题 | 系统、深色、浅色 | 改变整个应用的颜色模式。系统会跟随 macOS 显示模式，深色和浅色会把应用固定为对应模式并立即生效。 |

主题保存后会立刻应用。看板、任务详情和下一次应用启动都会复用同一偏好。

## Pane 布局

设置页中的 **面板布局设置** 链接会打开 tmux pane 分割和启动命令编辑器。

| 设置项 | 说明 |
| --- | --- |
| 全局默认值 | 项目没有专属设置时，所有新终端会话使用的默认布局。 |
| 项目专属设置 | 为单个项目覆盖布局和命令。没有 override 的项目继续使用全局默认值。 |
| 布局类型 | 可选择 `单面板`、`上下分割`、`左右分割`、`左 + 右上下`、`左上下 + 右`、`四分割`。 |
| Pane 启动命令 | 为每个 pane 位置输入启动命令。例如一个 pane 运行 `pnpm dev`，另一个 pane 运行测试或日志命令。 |
| 保存 / 重置 | 保存后会应用到未来创建的会话。项目专属设置可通过 **重置为全局默认值** 删除 override。 |

Pane 布局能让任务终端保持可重复。如果每个 worktree 都需要服务器、测试和日志窗口，可以把这些命令保存一次，新任务工作区就会以相同结构打开。

## 详情页

| 设置项 | 默认值 | 行为 |
| --- | --- | --- |
| 默认折叠侧栏 | 关闭 | 控制进入任务详情页时左侧信息面板是否默认折叠。想给终端留出更多空间时可开启；想一直看到标题、项目、优先级和会话信息时保持关闭。 |

该设置只改变任务详情工作区的打开方式，不会修改任务数据或终端会话。

## 任务创建

| 设置项 | 选项 | 行为 |
| --- | --- | --- |
| 默认会话类型 | `tmux`、`zellij`、`terminal` | 创建新任务时默认选择的终端后端。tmux 是默认值。使用 zellij 时，本机或远程目标环境需要安装 zellij。`terminal` 由 KanVibe 直接启动 shell、不使用多路复用器，无需额外安装；但应用退出或远程连接断开时，正在运行的工作也会一并消失。 |

会话类型设置只改变新建任务的默认选项，不会批量改写已有任务。

## 通知

| 设置项 | 选项 | 行为 |
| --- | --- | --- |
| 系统通知 | 开启 / 关闭 | 控制任务状态变化、PR 事件和后台 Sync 检查项是否可以显示系统通知。 |
| 通知状态 | PROGRESS、PENDING、REVIEW | 仅当任务变更为所选状态时发送通知。默认包含 PROGRESS、PENDING、REVIEW。TODO 和 DONE 通常由用户主动管理，因此不在状态过滤器中。 |

通知中心和系统通知会提示 AI 代理状态变化、PR 事件和后台 Sync 事件。点击已关联任务的通知，会直接打开该任务的详情工作区。缩小状态范围后，可以只保留 PENDING 提问或 REVIEW 待检查等真正需要关注的事件。

## 键盘

| 设置项 | 默认值 | 行为 |
| --- | --- | --- |
| Vim 风格看板操作 | 开启 | 在看板中启用 `h`/`j`/`k`/`l` 焦点移动、`n` 新建任务、`dd` 删除以及 `:move` 状态命令。关闭后方向键移动仍然可用。 |

完整按键列表请参见[快捷键](/zh/shortcuts)文档。

## 后台 Sync

| 设置项 | 范围 | 行为 |
| --- | --- | --- |
| 后台 Sync | 开启 / 关闭 | 应用打开时，定期检查项目 worktree、PR 状态和任务 pull 结果。 |
| 同步间隔 | 1–1440 分钟 | 后台 Sync 的执行频率。默认值为 10 分钟，以分钟保存。无效值不会保存，并会恢复到上一个有效值。 |

后台 Sync 会收集合并完成的 PR、新发现的 worktree、pull 成功或失败、PR 查询失败等检查项。即使某个同步阶段失败，其余阶段仍会继续执行，失败原因会显示在后台 Sync 检查通知中。
