# 功能

KanVibe 将看板、终端会话、git worktree 与 AI 代理 hooks 连接成一个工作流。

## 实时看板

<figure className="kv-shot">
  <img src="/screenshots/board.png" alt="KanVibe 主看板" />
  <figcaption>用项目颜色和任务元数据管理 TODO、PROGRESS、PENDING、REVIEW、DONE。</figcaption>
</figure>

<div className="kv-status-flow">
  <span>TODO</span><span>PROGRESS</span><span>PENDING</span><span>REVIEW</span><span>DONE</span>
</div>

- 通过拖拽移动卡片并调整顺序。
- 在卡片上直接查看项目颜色、优先级、PR 与会话标签。
- DONE 列支持分页，适合长期项目。

## 任务详情工作区

<figure className="kv-shot">
  <img src="/screenshots/task-detail.png" alt="每个任务的终端工作区" />
  <figcaption>每个任务都提供独立终端界面，可在 AI 代理执行、直接命令、构建和测试之间自由切换。</figcaption>
</figure>

- 在浏览器或桌面应用中打开 tmux / zellij 会话。
- 每个任务都有自己的终端，因此可把 AI 代理执行的任务随时接回并用 shell 命令继续处理。
- 用编号 dock 快捷键切换信息、hook 状态、AI 聊天和 PR 操作。
- 将任务移动到 DONE 时，会清理 branch、worktree 和终端会话。

## 任务级 AI 聊天历史

<div className="kv-grid">
  <figure className="kv-shot">
    <img src="/screenshots/ai-chat-provider-filters.png" alt="同时选择 Claude 和 Gemini 的 AI 聊天 provider 过滤器" />
    <figcaption>在左侧 provider 图标栏中同时选择多个代理时，会以 OR 条件显示所有匹配会话。</figcaption>
  </figure>
  <figure className="kv-shot">
    <img src="/screenshots/ai-chat-search.png" alt="AI 聊天正文搜索结果" />
    <figcaption>搜索不仅匹配会话标题，也会匹配对话正文，并直接打开相关消息上下文。</figcaption>
  </figure>
</div>

- 在任务详情的 AI 聊天面板中按需加载 Claude、Gemini、Codex、OpenCode 历史。
- Provider 过滤器可同时选择多个图标，已选择的 provider 会先以 OR 条件合并，再由其他过滤器继续缩小范围。
- 聊天搜索会同时缩小会话列表和消息详情，role chip 可进一步过滤用户输入、AI 回复、系统输入、开发者输入、推理、工具和其他消息。
- 每个消息气泡都会显示 provider 徽章，便于区分多代理上下文。

- 已关联任务的通知被点击后，会立即打开对应任务详情页。

## AI 代理 Hooks

| Agent | 自动状态流 | 安装位置 |
| --- | --- | --- |
| Claude Code | 用户提示 → PROGRESS，提问 → PENDING，回复完成 → REVIEW | `.claude/hooks/`, `.claude/settings.json` |
| Gemini CLI | BeforeAgent → PROGRESS，AfterAgent → REVIEW | `.gemini/hooks/`, `.gemini/settings.json` |
| Codex CLI | UserPromptSubmit → PROGRESS，PermissionRequest → PENDING，Stop → REVIEW | `.codex/hooks.json`, `.codex/config.toml` |
| OpenCode | message.updated → PROGRESS，question.asked → PENDING，session.idle → REVIEW | `.opencode/plugins/` |
