# 설치

KanVibe는 macOS 데스크톱 앱으로 배포되며, 현재 권장 설치 경로는 Homebrew Cask입니다.

## 사전 요구사항

| 의존성 | 필수 | 설명 | 설치 예시 |
| --- | --- | --- | --- |
| Git | 필수 | branch와 worktree 생성 및 정리 | `brew install git` |
| tmux | 권장 | 기본 세션 백엔드. 세션 타입을 `terminal`로 바꾸면 없어도 동작합니다 | `brew install tmux` |
| GitHub CLI `gh` | 필수 | PR URL 조회와 GitHub 워크플로우 | `brew install gh` 후 `gh auth login` |
| zellij | 선택 | tmux 대신 사용할 수 있는 세션 백엔드 | `brew install zellij` |

멀티플렉서 없이 쓰려면 세션 타입을 `terminal`로 고르면 됩니다. 대신 그 세션의 셸은 KanVibe가 직접 들고 있어서, 앱을 끄거나 원격 연결이 끊기면 실행 중이던 작업도 함께 사라집니다. 오래 도는 작업을 맡길 계획이라면 tmux나 zellij를 설치해 두는 편이 안전합니다.

## Homebrew로 설치

```bash
brew install --cask rookedsysc/kanvibe/kanvibe
open -a KanVibe
```

공식 Homebrew Cask 등록 후에는 아래 명령으로 설치할 수 있습니다.

```bash
brew install --cask kanvibe
```

## 업데이트와 제거

```bash
brew update
brew upgrade --cask kanvibe
```

```bash
brew uninstall --cask kanvibe
brew untap rookedsysc/kanvibe
```
