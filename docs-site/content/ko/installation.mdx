# 설치

Mac에 KanVibe Desktop을 설치해 AI 코딩 작업을 관리하고, iOS·Android Mobile 앱을 연결해 휴대폰이나 태블릿에서 이어가세요. Desktop은 Homebrew Cask로 설치하며, Mobile은 현재 소스에서 빌드해 사용합니다. [Mobile 빌드와 연결 안내](/ko/mobile)를 확인하세요.

## 사전 요구사항

| 의존성 | 필수 | 설명 | 설치 예시 |
| --- | --- | --- | --- |
| Git | 필수 | branch와 worktree 생성 및 정리 | `brew install git` |
| Herdr | 권장 | 기본 세션 백엔드. 0.9.5에서 검증했습니다. Mobile 터미널은 미지원 | KanVibe에서 `herdr` 선택 후 설치 안내 승인 |
| tmux | 선택 | 대체 세션 백엔드 | `brew install tmux` |
| GitHub CLI `gh` | 필수 | PR URL 조회와 GitHub 워크플로우 | `brew install gh` 후 `gh auth login` |
| zellij | 선택 | 대체 세션 백엔드 | `brew install zellij` |

멀티플렉서 없이 쓰려면 세션 타입을 `terminal`로 고르면 됩니다. 대신 그 세션의 셸은 KanVibe가 직접 들고 있어서, 앱을 끄거나 원격 연결이 끊기면 실행 중이던 작업도 함께 사라집니다. 오래 도는 작업을 맡길 계획이라면 Herdr, tmux, zellij 중 하나를 설치해 두는 편이 안전합니다.

태스크 생성·브랜치 생성·터미널 연결에서 `herdr`를 선택하면 로컬 또는 선택한 SSH 호스트의 설치 여부를 확인합니다. Herdr가 없으면 설치 안내를 승인해 해당 호스트에서 [공식 설치 프로그램](https://herdr.dev/tui/docs/install/)을 실행할 수 있습니다. `~/.local/bin`에 설치하며 셸 시작 파일은 바꾸지 않습니다. 취소하면 태스크는 변경되지 않습니다. 설치에 실패하면 오류를 확인하고 네트워크 연결과 설치 경로의 쓰기 권한을 점검한 뒤 다시 시도합니다.

## Homebrew로 설치

```bash
brew install --cask rookedsysc/kanvibe/kanvibe
open -a KanVibe
```

공식 Homebrew Cask 등록 후에는 아래 명령으로 설치할 수 있습니다.

```bash
brew install --cask kanvibe
```

## 업데이트와 제거

```bash
brew update
brew upgrade --cask kanvibe
```

```bash
brew uninstall --cask kanvibe
brew untap rookedsysc/kanvibe
```

## 휴대폰에서 이어가기

Desktop을 실행한 뒤 [Mobile 빌드·연결 가이드](/ko/mobile)에 따라 앱을 빌드하고 6자리 코드로 연결하세요. 휴대폰에서 로컬 또는 사설 네트워크를 통해 PC 주소에 접근할 수 있어야 합니다. 백그라운드 푸시에는 Firebase/APNs와 Desktop 중계 설정이 별도로 필요합니다. Mobile 터미널은 tmux, zellij, terminal 세션에서만 동작하므로, 휴대폰에서 쓸 태스크는 기본값인 Herdr 대신 이 중 하나를 고르세요.
