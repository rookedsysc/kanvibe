## 알림을 클릭하면 태스크로 이동

- 알림 센터와 브라우저 알림은 AI 에이전트 상태 변경, PR/백그라운드 Sync 이벤트를 알려줍니다.
- 태스크와 연결된 알림을 클릭하면 해당 태스크 상세 워크스페이스로 바로 이동합니다.
- 알림 받을 상태를 제한하면 PENDING 질문이나 REVIEW 완료처럼 바로 확인해야 하는 이벤트만 남길 수 있습니다.

## 프로젝트 등록과 정리

- 로컬 또는 SSH 호스트의 디렉터리를 스캔해 git 저장소를 KanVibe 프로젝트로 등록합니다.
- 등록된 프로젝트 목록에서 repo path, 기본 브랜치, SSH 호스트를 확인합니다.
- 더 이상 추적하지 않을 프로젝트는 설정 페이지에서 삭제합니다.
