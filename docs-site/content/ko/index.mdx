## 지금 어떤 작업에 손이 필요한지 확인하세요

터미널 탭을 하나씩 찾아다닐 필요가 없습니다. 보드에서 프로젝트, 브랜치, PR, 세션을 함께 확인하고, 지원하는 에이전트의 hooks로 작업 상태를 자동 갱신합니다.

## 작업 맥락이 남아 있는 터미널에서 계속하세요

Desktop에서는 Herdr, tmux, zellij, 일반 terminal 세션을 지원합니다. 브랜치 기반 태스크는 브랜치별 독립 작업 디렉터리인 git worktree와 터미널 세션을 연결합니다. 에이전트를 실행하고, 변경 사항과 대화 기록을 살펴보고, 직접 명령을 입력하세요. 검색, 프로젝트 필터, 패널 단축키로 다음 작업으로 빠르게 이동할 수 있습니다.

## 책상을 떠나도 같은 작업을 이어가세요

KanVibe Mobile은 실행 중인 Desktop 앱에 연결합니다. 보드를 확인하고, 태스크의 실제 터미널에 입력하고, 셸 탭을 추가하거나 저장된 PC를 전환할 수 있습니다. 휴대폰에서는 상태별 목록으로, 태블릿에서는 칸반 보드로 보여줍니다.

## PC에서 시작하고, 필요한 곳에서 이어가세요

1. **저장소 등록.** 로컬 또는 원격 프로젝트를 스캔해 worktree 브랜치를 보드에 모읍니다.
2. **태스크 시작.** 브랜치별 작업 공간에서 에이전트를 실행하고 보드로 상태를 확인합니다.
3. **휴대폰 연결.** Desktop의 연결 코드를 한 번 입력하면 Mobile에서 같은 태스크와 터미널을 열 수 있습니다. 휴대폰에서 쓸 태스크는 tmux, zellij, terminal 세션으로 만드세요.
