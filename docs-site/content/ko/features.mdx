# 기능

KanVibe는 칸반 보드, 터미널 세션, git worktree, AI 에이전트 hooks를 하나의 워크플로우로 연결합니다.

## 실시간 칸반 보드

<figure className="kv-shot">
  <img src="/screenshots/board.png" alt="KanVibe 메인 칸반 보드" />
  <figcaption>TODO, PROGRESS, PENDING, REVIEW, DONE 상태를 프로젝트 색상과 함께 관리합니다.</figcaption>
</figure>

<div className="kv-status-flow">
  <span>TODO</span><span>PROGRESS</span><span>PENDING</span><span>REVIEW</span><span>DONE</span>
</div>

- 드래그 앤 드롭으로 상태와 순서를 변경합니다.
- 프로젝트 색상, 우선순위, PR, 세션 타입을 카드에서 바로 확인합니다.
- DONE 컬럼은 장기 프로젝트를 위해 페이지네이션을 제공합니다.

## 태스크 상세 워크스페이스

<figure className="kv-shot">
  <img src="/screenshots/terminal-workspace.png" alt="태스크별 터미널 워크스페이스" />
  <figcaption>각 태스크는 독립 터미널 인터페이스를 제공해 AI 에이전트 실행, 직접 명령, 빌드/테스트를 자유롭게 오갈 수 있습니다.</figcaption>
</figure>

- tmux 또는 zellij 세션을 브라우저/데스크톱에서 열 수 있습니다.
- 각 태스크가 자기 터미널을 가지므로 AI에게 맡긴 작업을 그대로 이어서 직접 명령으로 보정할 수 있습니다.
- 상세 dock 단축키로 정보, hook 상태, AI 채팅, PR을 전환합니다.
- 작업이 DONE으로 이동하면 branch, worktree, terminal session을 정리합니다.

- 프로젝트 필터는 보드에 보이는 프로젝트만 빠르게 좁혀 집중도를 높입니다.
- 알림 센터와 브라우저 알림은 AI 에이전트 상태 변경, PR, 백그라운드 Sync 이벤트를 모아 보여줍니다.
- 태스크와 연결된 알림은 클릭 즉시 해당 태스크 상세 화면으로 이동합니다.

## AI 에이전트 Hooks

| Agent | 자동 상태 흐름 | 설치 위치 |
| --- | --- | --- |
| Claude Code | 사용자 프롬프트 → PROGRESS, 질문 → PENDING, 응답 완료 → REVIEW | `.claude/hooks/`, `.claude/settings.json` |
| Gemini CLI | BeforeAgent → PROGRESS, AfterAgent → REVIEW | `.gemini/hooks/`, `.gemini/settings.json` |
| Codex CLI | UserPromptSubmit → PROGRESS, PermissionRequest → PENDING, Stop → REVIEW | `.codex/hooks.json`, `.codex/config.toml` |
| OpenCode | message.updated → PROGRESS, question.asked → PENDING, session.idle → REVIEW | `.opencode/plugins/` |
