# 기능

KanVibe는 칸반 보드, 터미널 세션, git worktree, AI 에이전트 hooks를 하나의 워크플로우로 연결합니다.

- 드래그 앤 드롭으로 카드 상태를 바꾸고, 정렬 필터로 카드 순서를 정합니다.
- 프로젝트 색상, 우선순위, PR, 세션 타입을 카드에서 바로 확인합니다.
- DONE 컬럼은 장기 프로젝트를 위해 페이지네이션을 제공합니다.

## 태스크 상세 워크스페이스

<figure className="kv-shot">
  <img src="/screenshots/task-detail.png" alt="태스크별 터미널 워크스페이스" />
  <figcaption>각 태스크는 독립 터미널 인터페이스를 제공해 AI 에이전트 실행, 직접 명령, 빌드/테스트를 자유롭게 오갈 수 있습니다.</figcaption>
</figure>

- 세션 백엔드를 tmux, zellij, 그리고 멀티플렉서 없이 KanVibe가 셸을 직접 띄우는 terminal 중에서 고릅니다.
- 각 태스크가 자기 터미널을 가지므로 AI에게 맡긴 작업을 그대로 이어서 직접 명령으로 보정할 수 있습니다.
- 상세 dock 단축키로 정보, hook 상태, AI 채팅, PR을 전환합니다.
- DONE으로 이동해도 branch, worktree, terminal session은 그대로 남습니다. 리소스 정리는 태스크를 삭제할 때만 실행됩니다.

## 터미널 탭

한 태스크 안에서 터미널을 여러 개 열어 서버, 테스트, 에이전트 실행을 나눠 둘 수 있습니다.

<figure className="kv-shot">
  <img src="/screenshots/terminal-tabs.png" alt="claude, dev server, test 세 개의 터미널 탭이 열린 태스크 상세 화면" />
  <figcaption>터미널 위쪽 탭 바에서 오른쪽 <code>+</code> 버튼으로 탭을 추가합니다. 앞 다섯 개 탭에는 바로 이동하는 단축키가 함께 표시되고, 선택한 탭의 터미널이 그대로 아래에 이어집니다.</figcaption>
</figure>

- 탭 바에서 탭을 추가·전환·닫고, 더블클릭으로 이름을 바꾸고, 드래그로 순서를 옮깁니다.
- 작업 정보 패널이 열려 있으면 탭 바 왼쪽 일부를 덮습니다. 패널 밖 터미널을 클릭하거나 dock의 작업 정보 버튼을 다시 눌러 닫으면 탭 바 전체가 드러납니다.
- tmux와 zellij 세션의 탭은 각각 tmux window, zellij tab과 **양방향으로 동기화**됩니다. KanVibe 밖에서 `tmux new-window`로 만든 window도 탭 바에 나타나고, 탭을 클릭하면 멀티플렉서의 활성 대상도 함께 바뀝니다.
- 멀티플렉서 세션에서는 KanVibe가 자체 탭 바를 그리므로 tmux 상태바와 zellij 탭 바는 KanVibe가 만든 세션에 한해 꺼둡니다. tmux는 세션에 다시 붙을 때마다 꺼주므로 탭 바가 들어오기 전에 만든 세션도 정리됩니다. zellij는 레이아웃이 세션을 만들 때 정해져, 그 뒤에 새로 만든 세션부터 적용됩니다.
- `terminal` 세션에서는 KanVibe가 탭마다 셸을 직접 띄웁니다. 탭을 옮겨 다녀도 각 탭의 스크롤백이 유지되고, 앱이 켜져 있는 동안 셸도 살아 있습니다.

키 조합은 [단축키](/ko/shortcuts) 문서의 터미널 탭 절에 정리돼 있습니다.

- 말풍선에는 provider 배지가 붙어 어떤 에이전트의 메시지인지 한눈에 구분할 수 있습니다.

## 실행중 AI 세션과 서브태스크

  <figure className="kv-shot">
    <img src="/screenshots/live-sessions-board.png" alt="보드 카드의 tmux 배지 옆에 실행중 에이전트 아이콘이 붙은 화면" />
    <figcaption>tmux 배지 옆에 에이전트 아이콘과 실행중 개수가 붙어, 어느 태스크에서 몇 개가 돌고 있는지 보드에서 바로 보입니다.</figcaption>
  </figure>
  <figure className="kv-shot">
    <img src="/screenshots/live-sessions-panel.png" alt="실행중 claude 세션과 서브태스크 2개를 보여주는 태스크 상세 패널" />
    <figcaption>세션 패널은 각 세션이 지금 붙들고 있는 작업과 실행중인 서브태스크를 함께 보여줍니다.</figcaption>
  </figure>
</div>

- 보드 카드에 포커스를 두거나 마우스를 올린 채 잠시 기다리면 세션 패널이 열립니다. 카드 사이를 빠르게 훑고 지나갈 때는 열리지 않습니다.
- 각 세션 줄에는 그 세션이 지금 붙들고 있는 작업이 표시됩니다. 가장 최근 사용자 요청에서 뽑으므로 대화가 길어져도 현재 하는 일을 가리킵니다.
- 태스크 상세에서는 dock의 실행중 세션 항목으로 같은 패널을 엽니다. PR이 없으면 `Mod+4`, PR이 있으면 `Mod+5`입니다.
- 세션을 클릭하면 그 세션이 붙어 있는 tmux window로 전환하고 터미널에 입력 포커스를 넘깁니다.
- 실행중 판정은 두 근거를 겹칩니다. tmux pane에 에이전트가 붙어 있으면 입력을 기다리는 중이어도 실행중이고, pane이 보이지 않아도 세션 기록이 방금 갱신됐으면 실행중입니다.
- 패널이 열려 있는 동안에만 세션 기록을 읽습니다. 보드 배지는 tmux 조회 한 번으로 그려서 카드가 많아도 부담이 늘지 않습니다.

서브태스크 집계는 에이전트마다 근거가 달라 지원 범위가 나뉩니다.

| 에이전트 | 서브태스크 집계 |
| --- | --- |
| Claude Code | 지원 |
| Codex | 지원 |
| OpenCode | 버전에 따라 다름 |
| Gemini CLI | 미지원 |

tmux를 쓰지 않는 zellij와 terminal 세션은 기록 활동만으로 판정하므로, 입력을 기다리며 대기 중인 세션이 유휴로 보일 수 있습니다.

    <figcaption>보드에 표시할 프로젝트를 키보드로 토글합니다.</figcaption>
  </figure>
  <figure className="kv-shot">
    <img src="/screenshots/notifications.png" alt="알림 센터" />
    <figcaption>알림을 클릭하면 연결된 태스크 상세 워크스페이스로 바로 이동합니다.</figcaption>
  </figure>
</div>

- 프로젝트 필터는 보드에 보이는 프로젝트만 빠르게 좁혀 집중도를 높입니다.
- 프로젝트 필터와 + 새 작업 사이의 돋보기 버튼은 디렉터리 스캔과 저장소 등록을 위한 프로젝트 등록 dialog를 엽니다.
- 알림 센터와 시스템 알림은 AI 에이전트 상태 변경, PR, 백그라운드 Sync 이벤트를 모아 보여줍니다.
- 태스크와 연결된 알림은 클릭 즉시 해당 태스크 상세 화면으로 이동합니다.
- 알림 목록에서 `Space`는 선택한 알림을 읽음 처리만 하고, `Enter`는 대상 화면으로 이동합니다.
- 태스크 상세 화면에 들어가면 그 태스크로 쌓인 알림은 자동으로 모두 읽음 처리됩니다.
- 칸반 카드에는 읽지 않은 알림 개수가 배지로 표시되어 보드에서 바로 확인할 수 있습니다.

## AI 에이전트 Hooks

| Agent | 자동 상태 흐름 | 설치 위치 |
| --- | --- | --- |
| Claude Code | 사용자 프롬프트 → PROGRESS, 질문 → PENDING, 응답 완료 → REVIEW | `.claude/hooks/`, `.claude/settings.json` |
| Gemini CLI | BeforeAgent → PROGRESS, AfterAgent → REVIEW | `.gemini/hooks/`, `.gemini/settings.json` |
| Codex CLI | UserPromptSubmit → PROGRESS, PermissionRequest → PENDING, Stop → REVIEW | `.codex/hooks.json`, `.codex/config.toml` |
| OpenCode | message.updated → PROGRESS, question.asked → PENDING, session.idle → REVIEW | `.opencode/plugins/` |
