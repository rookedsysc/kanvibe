# 단축키

KanVibe는 터미널 포커스를 깨지 않도록 전역/보드/상세 단축키를 명확히 분리합니다.

  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + O</kbd><strong>빠른 태스크 검색</strong><p>브랜치명 또는 프로젝트명으로 전체 태스크를 찾습니다.</p></div>
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + P</kbd><strong>프로젝트 필터</strong><p>보드에 표시할 프로젝트를 토글합니다.</p></div>
  <div className="kv-kbd-card"><kbd>Cmd/Ctrl + Shift + I</kbd><strong>알림 센터</strong><p>AI 에이전트 상태 변경과 이벤트 알림을 엽니다.</p></div>

## 전체 단축키 표

| 단축키 | 범위 | 동작 |
| --- | --- | --- |
| `Cmd/Ctrl+F` | 보드 | 현재 보이는 프로젝트/태스크 텍스트 검색 |
| `Cmd/Ctrl+Shift+O` | 전역 | 브랜치명/프로젝트명 기준 빠른 태스크 검색 |
| `Cmd/Ctrl+Shift+P` | 보드 | 프로젝트 필터 드롭다운 열기 |
| `Cmd/Ctrl+Shift+I` | 보드 | 알림 드롭다운 열기 |
| `Cmd+[` / `Cmd+]` (macOS), `Ctrl+[` / `Ctrl+]` (Linux) | 전역 | 앱 히스토리 뒤로/앞으로 이동 |
| `Cmd/Ctrl+Shift+N` | 전역 | 현재 화면을 새 창으로 열기 |
| `Cmd/Ctrl+1/2/3` | 태스크 상세 | 정보, 상태/hooks, AI 채팅 dock 항목 활성화 |
| `Cmd/Ctrl+4` | 태스크 상세 | PR이 있으면 브라우저에서 PR 열기 |
| `Cmd/Ctrl+0` | 태스크 상세 | AI 사용량 패널 열기/닫기 (dock 번호를 쓰지 않는 별도 슬롯) |
| `Cmd/Ctrl+N` | 전역 | 새 작업 모달 열기. 빠른 태스크 검색에서는 하이라이트된 태스크 기준으로 새 branch TODO를 만듭니다 |
| `↑ / ↓ / Enter / Shift+Enter / Esc` | 빠른 태스크 검색 | 선택 이동, 열기, 새 창 열기, 닫기 |
| `↑ / ↓ / Enter / Esc` | 프로젝트 필터 | 선택 이동, 토글, 닫기 |
| `↑ / ↓ / Space / Enter / Esc` | 알림 | 선택 이동, 읽음 처리, 대상 열기, 닫기 |

## 터미널 탭

탭 조작은 태스크 상세의 터미널이 보이는 동안 동작하고, 창 닫기는 어느 화면에서나 동작합니다. tmux·zellij 세션에서는 멀티플렉서의 window/tab을 그대로 조작합니다.

| 단축키 | 동작 |
| --- | --- |
| `Cmd/Ctrl+T` | 새 탭 |
| `Cmd/Ctrl+W` | 현재 탭 닫기. 마지막 탭이면 창까지 닫되 tmux·zellij 탭은 지우지 않아 세션이 남습니다. 터미널이 없는 화면에서는 창을 닫습니다 |
| `Cmd/Ctrl+Shift+W` | 탭과 무관하게 창 닫기 |
| `Cmd/Ctrl+Shift+[` / `Cmd/Ctrl+Shift+]` | 이전 / 다음 탭 |
| `Cmd+Option+1` ~ `Cmd+Option+5` (macOS), `Ctrl+Alt+1` ~ `Ctrl+Alt+5` (Linux) | 1~5번 탭으로 바로 이동 |

<div className="kv-note">
  Linux에서는 이 단축키들이 `Ctrl` 조합이라 터미널 안의 `Ctrl+T`(문자 교환), `Ctrl+W`(단어 삭제), `Ctrl+[`(ESC)가 셸로 전달되지 않습니다.
</div>

## Vim 모드

보드에서 h/j/k/l 포커스 이동, `n` 새 태스크, `dd` 삭제, `:move` 상태 변경, `/` 검색을 Vim 스타일로 사용할 수 있습니다. 기본값은 **켜짐**이며, 설정 → 키보드 → "Vim 스타일 보드 조작" 토글로 끄거나 켤 수 있습니다.

<div className="kv-note">
  Vim 모드를 꺼도 방향키(Arrow Keys) 기반 포커스 이동은 그대로 유지됩니다.
</div>

### Vim 단축키 표

| 단축키 | 동작 |
| --- | --- |
| `h` | 왼쪽 컬럼으로 포커스 이동 |
| `j` | 같은 컬럼에서 아래 태스크로 이동 |
| `k` | 같은 컬럼에서 위 태스크로 이동 |
| `l` | 오른쪽 컬럼으로 포커스 이동 |
| `n` | 새 태스크 생성 모달 열기 |
| `dd` | 포커스된 태스크 삭제 (확인 대화상자 표시) |
| `/` | 보드 페이지 검색 열기 |
| `:` | 명령 입력창 열기 |

### `:move` 명령

명령 입력창(`:`)에서 `move` 뒤에 상태를 입력하면 포커스된 태스크의 상태를 변경합니다. `move re` → `move review`처럼 유일한 명령/상태 prefix는 `Tab`으로 자동 완성할 수 있습니다.

```
:move progress
:move pending
:move review
:move done
:move todo
```

축약어도 지원합니다: `t`(todo), `prog`(progress), `pend`(pending), `rev`(review), `d`(done).
