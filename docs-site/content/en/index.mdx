## Know where every task stands

Stop hunting through terminal tabs. The board brings together project, branch, PR, and session context, while supported agent hooks update task status as work progresses.

## Keep the terminal that already has your context

Desktop supports Herdr, tmux, zellij, and plain terminal sessions. Each branch-based task connects a git worktree, an isolated working directory for the branch, with its terminal session. Run an agent, check a diff, review conversation history, or type a command yourself. Search, project filters, and dock shortcuts keep the next action close.

## Step away from the desk, stay with the task

KanVibe Mobile connects to your running Desktop app. Check the board, open a task's actual terminal, send input, add a shell tab, or switch between saved PCs. The phone shows a compact task list; tablets show a Kanban board.

## Start at your desk. Continue where you are.

1. **Register a repository.** Scan a local or remote project and bring its worktree branches onto the board.
2. **Start a task.** Create a branch workspace, run your agent, and follow its status on the board.
3. **Pair your phone.** Enter the Desktop connection code once, then open the same tasks and terminals from Mobile.
