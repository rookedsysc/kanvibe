<div className="kv-grid">
  <div className="kv-card">
    <h3>Branch-based task management</h3>
    <p>Create a task and KanVibe binds the branch, worktree, and tmux/zellij session into one work unit.</p>
  </div>
  <div className="kv-card">
    <h3>AI agent hooks</h3>
    <p>Claude, Gemini, Codex, and OpenCode events automatically move tasks through PROGRESS, PENDING, and REVIEW.</p>
  </div>
  <div className="kv-card">
    <h3>Task-scoped AI chat history</h3>
    <p>Load Claude, Gemini, Codex, and OpenCode conversations inside a task, then find the right context with provider OR filters, body search, and role filters.</p>
  </div>
  <div className="kv-card">
    <h3>Per-task terminal interface</h3>
    <p>Every task owns its own session — tmux, zellij, or a plain terminal without a multiplexer — so you can hand work to an AI agent or run shell commands yourself.</p>
  </div>
  <div className="kv-card">
    <h3>Terminal tabs</h3>
    <p>Split a server, a test run, and an agent session into tabs inside one task. Tabs stay synchronized in both directions with tmux windows and zellij tabs, so a window created outside KanVibe shows up in the tab bar.</p>
  </div>
  <div className="kv-card">
    <h3>Keyboard-first UI</h3>
    <p>Open filters, quick search, notifications, and detail panels with shortcuts while terminal focus stays predictable.</p>
  </div>
  <div className="kv-card">
    <h3>New worktree auto-detection</h3>
    <p>Background Sync periodically scans projects, discovers externally created git worktrees, and automatically registers them as tasks with hooks installed.</p>
  </div>
  <div className="kv-card">
    <h3>Merged PR auto-detection</h3>
    <p>Periodically checks PR status via GitHub CLI. When a merged PR is found, KanVibe sends a notification and prompts transition to DONE.</p>
  </div>
  <div className="kv-card">
    <h3>Notification center</h3>
    <p>Open the notification center with Cmd+Shift+I to see AI agent status changes, PR merges, and jump directly to the relevant task.</p>
  </div>
  <div className="kv-card">
    <h3>Session auto-linking</h3>
    <p>Background Sync detects running tmux/zellij sessions and automatically links them to the matching task, moving it to PROGRESS.</p>
  </div>
  <div className="kv-card">
    <h3>Delete auto-cleanup</h3>
    <p>Deleting a task automatically cleans up its git worktree, branch, and terminal session in the background. Moving a task to DONE alone cleans up nothing, and the project root branch is protected.</p>
  </div>
</div>
