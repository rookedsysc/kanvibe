## Notifications jump to tasks

- The notification center and browser notifications surface AI agent state changes, PR events, and background sync events.
- Clicking a notification that is linked to a task opens that task detail workspace directly.
- Restricting notification statuses lets you keep only the events that need attention, such as PENDING questions or REVIEW-ready work.

## Project registration and cleanup

- Scan local or SSH-hosted directories and register git repositories as KanVibe projects.
- Review each registered project's repo path, default branch, and SSH host from the project list.
- Delete projects from Settings when you no longer want KanVibe to track them.
