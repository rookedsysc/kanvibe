# Installation

KanVibe is distributed as a macOS desktop app. The recommended install path is Homebrew Cask.

## Prerequisites

| Dependency | Required | Why it is needed | Install example |
| --- | --- | --- | --- |
| Git | Required | Branch and worktree creation/cleanup | `brew install git` |
| tmux | Required | Default terminal session backend | `brew install tmux` |
| GitHub CLI `gh` | Required | PR URL lookup and GitHub workflows | `brew install gh`, then `gh auth login` |
| zellij | Optional | Alternative session backend | `brew install zellij` |

## Install with Homebrew

```bash
brew install --cask rookedsysc/kanvibe/kanvibe
open -a KanVibe
```

After KanVibe is accepted into the official Homebrew Cask repository, the command becomes:

```bash
brew install --cask kanvibe
```

## Update or remove

```bash
brew update
brew upgrade --cask kanvibe
```

```bash
brew uninstall --cask kanvibe
brew untap rookedsysc/kanvibe
```

## Quick Start

This is the default routine for starting AI agent work, tracking progress, and finishing the task in KanVibe.

### 1. Register a project

Choose a local git repository from settings. KanVibe reads existing worktree state and installs the required hook files for supported agents.

<div className="kv-note">
  Deleting a project removes KanVibe SQLite records only. Existing git branches, worktrees, and files remain on disk.
</div>

### 2. Create a task

Add a TODO task from the board. When you provide a branch name, KanVibe creates a git worktree and attaches a tmux or zellij session.

<figure className="kv-shot">
  <img src="/screenshots/quick-action.png" alt="Create a branch TODO from a quick action" />
  <figcaption>Create follow-up branch TODOs from quick search while preserving the current context.</figcaption>
</figure>

### 3. Work in task detail

Opening a task card moves you to its terminal workspace. The left dock switches task info, hook status, AI chat, and PR links, while the main terminal remains available for manual commands and agent interaction.

<figure className="kv-shot">
  <img src="/screenshots/detail-shortcuts.png" alt="Task detail dock shortcuts" />
  <figcaption>Dock shortcuts are handled before terminal input so focus stays predictable.</figcaption>
</figure>

### 4. Let AI agents update status

When an agent starts work, the task moves to PROGRESS. If it asks a question, it can move to PENDING. When the response finishes, it moves to REVIEW. Manual drag-and-drop uses the same status model, so the board and task detail stay aligned.

### 5. Finish with DONE

When the task is complete, move it to DONE. KanVibe automatically cleans up the task branch, worktree, and terminal session.
