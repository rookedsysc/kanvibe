# Installation

Install KanVibe Desktop on your Mac to manage AI coding work. Then pair the iOS or Android Mobile companion to continue from your phone or tablet. Desktop uses Homebrew Cask; Mobile is currently built from source. [Mobile build and pairing guide](/en/mobile).

## Prerequisites

| Dependency | Required | Why it is needed | Install example |
| --- | --- | --- | --- |
| Git | Required | Branch and worktree creation/cleanup | `brew install git` |
| Herdr | Recommended | Default session backend; verified with 0.9.5; not supported by Mobile terminals | Select `herdr` in KanVibe and accept the install prompt |
| tmux | Optional | Alternative session backend | `brew install tmux` |
| GitHub CLI `gh` | Required | PR URL lookup and GitHub workflows | `brew install gh`, then `gh auth login` |
| zellij | Optional | Alternative session backend | `brew install zellij` |

To work without a multiplexer, choose the `terminal` session type. KanVibe then owns that shell directly, so running work disappears when the app quits or a remote connection drops. Install Herdr, tmux, or zellij if you plan to leave long-running work unattended.

When creating, branching, or connecting a task with `herdr`, KanVibe checks the selected local or SSH host. If Herdr is missing, accepting the prompt runs the [official installer](https://herdr.dev/tui/docs/install/) on that host into `~/.local/bin`, without changing shell startup files. Cancelling leaves the task unchanged. If installation fails, check the reported error, network access, and directory permissions before retrying.

## Install with Homebrew

```bash
brew install --cask rookedsysc/kanvibe/kanvibe
open -a KanVibe
```

After KanVibe is accepted into the official Homebrew Cask repository, the command becomes:

```bash
brew install --cask kanvibe
```

## Update or remove

```bash
brew update
brew upgrade --cask kanvibe
```

```bash
brew uninstall --cask kanvibe
brew untap rookedsysc/kanvibe
```

## Continue on your phone

Once Desktop is running, follow the [Mobile build and pairing guide](/en/mobile) to build the companion and pair it with a six-digit code. Your phone must be able to reach the PC address over a local or private network. Background push requires separate Firebase/APNs and Desktop relay setup. Mobile terminals need a tmux, zellij, or terminal session, so choose one of these instead of the default Herdr for tasks you want on your phone.
