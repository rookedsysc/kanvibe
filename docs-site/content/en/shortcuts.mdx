# Shortcuts

KanVibe keeps global, board, and task-detail shortcuts separated so terminal focus remains predictable.

## Full shortcut reference

| Shortcut | Scope | Action |
| --- | --- | --- |
| `Cmd/Ctrl+F` | Board | Search visible project/task text |
| `Cmd/Ctrl+Shift+O` | Global | Open quick task search by branch or project name |
| `Cmd/Ctrl+Shift+P` | Board | Open the project filter dropdown |
| `Cmd/Ctrl+Shift+I` | Board | Open the notifications dropdown |
| `Cmd+[` / `Cmd+]` (macOS), `Ctrl+[` / `Ctrl+]` (Linux) | Global | Navigate back/forward through app history |
| `Cmd/Ctrl+Shift+N` | Global | Open the current view in a new window |
| `Cmd+Option+1/2/3` (macOS), `Alt+1/2/3` (Linux) | Task detail | Activate info, status/hooks, and AI chat dock items |
| `Cmd+4` (macOS), `Alt+4` (Linux) | Task detail | Open the PR in the browser when a PR exists |
| `Cmd/Ctrl+N` | Global | Open the new task modal. Inside quick task search it creates a branch TODO from the highlighted task |
| `↑ / ↓ / Enter / Shift+Enter / Esc` | Quick task search | Move selection, open, open in new window, close |
| `↑ / ↓ / Enter / Esc` | Project filter | Move selection, toggle, close |
| `↑ / ↓ / Enter / Esc` | Notifications | Move selection, open target, close |

## Terminal tabs

Tab actions work while the task detail terminal is visible; closing the window works anywhere. On tmux and zellij sessions they drive the multiplexer's own windows and tabs.

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl+T` | New tab |
| `Cmd/Ctrl+W` | Close the current tab; closes the window when it was the last tab, or when no terminal is open |
| `Cmd/Ctrl+Shift+W` | Close the window regardless of open tabs |
| `Cmd/Ctrl+Shift+[` / `Cmd/Ctrl+Shift+]` | Previous / next tab |
| `Cmd/Ctrl+1` – `Cmd/Ctrl+5` | Jump straight to tab 1–5 |

<div className="kv-note">
  On Linux these use `Ctrl`, so `Ctrl+T` (transpose), `Ctrl+W` (delete word), and `Ctrl+[` (ESC) no longer reach the shell inside the terminal.
</div>

## Vim mode

Use h/j/k/l for focus navigation, `n` for new task, `dd` for delete, `:move` for status change, and `/` for search — all in Vim style on the board. Vim mode is **on by default** and can be toggled in Settings → Keyboard → "Vim-style board controls".

<div className="kv-note">
  Arrow key focus navigation remains available even when Vim mode is off.
</div>

### Vim shortcut reference

| Shortcut | Action |
| --- | --- |
| `h` | Move focus to the left column |
| `j` | Move focus down within the same column |
| `k` | Move focus up within the same column |
| `l` | Move focus to the right column |
| `n` | Open the new task modal |
| `dd` | Delete the focused task (shows confirmation dialog) |
| `/` | Open the board page search |
| `:` | Open the command input |

### `:move` command

Type `move` followed by a status in the command input (`:`) to change the focused task's status. Press `Tab` to autocomplete a unique command/status prefix, such as `move re` → `move review`.

```
:move progress
:move pending
:move review
:move done
:move todo
```

Aliases are also supported: `t` (todo), `prog` (progress), `pend` (pending), `rev` (review), `d` (done).
