# Shortcuts

KanVibe keeps global, board, and task-detail shortcuts separated so terminal focus remains predictable.

## Full shortcut reference

| Shortcut | Scope | Action |
| --- | --- | --- |
| `Cmd/Ctrl+F` | Board | Search visible project/task text |
| `Cmd/Ctrl+Shift+O` | Global | Open quick task search by branch or project name |
| `Cmd+Option` (macOS), `Ctrl+Alt` (Linux), press and release | Worktree view | Focus the selected task in the left list; does not run when combined with another key |
| `↑ / ↓` | Focused Worktree task list | Select the previous/next task and show its terminal; stop at the first/last task |
| `Enter` | Focused Worktree task list | Focus the selected task's terminal |
| `Cmd/Ctrl+Shift+P` | Board | Open the project filter dropdown |
| `Cmd/Ctrl+Shift+I` | Board | Open the notifications dropdown |
| `Cmd+[` / `Cmd+]` (macOS), `Ctrl+[` / `Ctrl+]` (Linux) | Global | Navigate back/forward through app history |
| `Cmd/Ctrl+Shift+N` | Global | Open the current view in a new window |
| `Cmd/Ctrl+1/2/3` | Task detail | Activate info, status/hooks, and AI chat dock items |
| `Cmd/Ctrl+4` | Task detail | Open the PR in the browser when a PR exists |
| `Cmd/Ctrl+0` | Task detail | Toggle the AI usage panel (a separate slot that does not consume a dock number) |
| `Cmd/Ctrl+N` | Global | Open the new task modal. Inside quick task search it creates a branch TODO from the highlighted task |
| `↑ / ↓ / Enter / Shift+Enter / Esc` | Quick task search | Move selection, open, open in new window, close |
| `↑ / ↓ / Enter / Esc` | Project filter | Move selection, toggle, close |
| `↑ / ↓ / Space / Enter / Esc` | Notifications | Move selection, mark as read, open target, close |

## Worktree list navigation

Press and release only `Cmd+Option` on macOS or `Ctrl+Alt` on Linux to focus the currently selected task in the left list. This runs on release, and does not run if you use another key in the same combination. With the list focused, `↑ / ↓` changes both the selected task and the right terminal; navigation stops at the first/last task. `Enter` moves focus into the selected task's terminal.

In Worktree view, choosing a `Cmd/Ctrl+Shift+O` search result keeps the split view open and reveals the selected task in the left list, including DONE tasks and tasks hidden by the current filters. In Kanban view, choosing a result still opens task detail. `Shift+Enter` in search continues to open task detail in a new window.

## Terminal tabs

Tab actions work while the task detail terminal is visible; closing the window works anywhere. On Herdr, tmux, and zellij sessions they drive the multiplexer's own windows and tabs.

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl+T` | New tab |
| `Cmd/Ctrl+W` | Close the current tab. On the last tab it closes the window but keeps the Herdr/tmux/zellij tab, so the session survives. Closes the window when no terminal is open |
| `Cmd/Ctrl+Shift+W` | Close the window regardless of open tabs |
| `Cmd/Ctrl+Shift+[` / `Cmd/Ctrl+Shift+]` | Previous / next tab |
| `Cmd+Option+1` – `Cmd+Option+5` (macOS), `Ctrl+Alt+1` – `Ctrl+Alt+5` (Linux) | Jump straight to tab 1–5 |

<div className="kv-note">
  On Linux these use `Ctrl`, so `Ctrl+T` (transpose), `Ctrl+W` (delete word), and `Ctrl+[` (ESC) no longer reach the shell inside the terminal.
</div>

## Vim mode

Use h/j/k/l for focus navigation, `n` for new task, `dd` for delete, `:move` for status change, and `/` for search — all in Vim style on the board. Vim mode is **on by default** and can be toggled in Settings → Keyboard → "Vim-style board controls".

<div className="kv-note">
  Arrow key focus navigation remains available even when Vim mode is off.
</div>

### Vim shortcut reference

| Shortcut | Action |
| --- | --- |
| `h` | Move focus to the left column |
| `j` | Move focus down within the same column |
| `k` | Move focus up within the same column |
| `l` | Move focus to the right column |
| `n` | Open the new task modal |
| `dd` | Delete the focused task (shows confirmation dialog) |
| `/` | Open the board page search |
| `:` | Open the command input |

### `:move` command

Type `move` followed by a status in the command input (`:`) to change the focused task's status. Press `Tab` to autocomplete a unique command/status prefix, such as `move re` → `move review`.

```
:move progress
:move pending
:move review
:move done
:move todo
```

Aliases are also supported: `t` (todo), `prog` (progress), `pend` (pending), `rev` (review), `d` (done).
